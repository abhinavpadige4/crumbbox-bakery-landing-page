# CrumbBox Bakery Landing Page

A responsive landing page for CrumbBox bakery brand built with vanilla HTML, CSS, and JavaScript.

## Features

- Hero section with bakery tagline and call-to-action button
- Menu section displaying items with prices and images
- About our bakers section with photos and short bios
- Testimonials section with customer quotes and ratings
- Order/contact section with form and submit button
- Responsive layout for mobile, tablet, desktop
- Warm cream and brown color scheme
- Accessible (WCAG AA) – proper contrast, ARIA labels, keyboard navigation
- SEO-friendly meta tags
- Clean, semantic HTML5
- CSS using CSS variables for design tokens

## Design Tokens

The project uses CSS variables for consistent theming:
- `--cream`: #FFF8E7 (background)
- `--brown`: #8B5E3C (primary)
- `--dark-brown`: #5C4033 (text)
- `--accent`: #D4A373 (secondary accents)
- `--font-primary`: 'Playfair Display', serif (headings)
- `--font-secondary`: 'Montserrat', sans-serif (body text)

## Deployment

## Development

To run locally:

2. Open `index.html` in your browser
3. No build process required - pure HTML/CSS/JS
